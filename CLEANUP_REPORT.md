# Portfolio visual simplification

## Changes
- Removed the boxed s. logo and stylized wordmark from the header and footer. Navigation now uses the owner's plain name.
- Removed duplicate social icons from the header; social links remain in Hero, Contact and footer.
- Replaced oversized illustrated project cards with compact, text-led cards. Decorative cover images are no longer displayed. Future genuine screenshots remain supported; older illustrations are retained as unused source assets.
- Desktop projects use three columns, tablet two columns, and mobile one column. Technology labels and ownership are simple text; Team Project disclosure and notes remain visible.
- Reduced card padding, border radii and heavy hover treatments. Simplified skill labels by removing faux technology monograms and the redundant connection diagram.
- Tightened technical/leadership credential cards while preserving all seven entries, names, issuers, dates and verification links.
- Removed repetitive decorative rows and the additional GitHub promotional banner; existing GitHub links remain available. Used direct section headings and more consistent spacing.
- Preserved the supplied portrait, transparent hero treatment, compact emerald glow, all five curated projects, seven certificates, education, developer journey, contact details and both CV downloads.

## Files
`src/components/navigation.tsx`, `src/components/projects.tsx`, `src/components/sections.tsx`, `src/components/certifications.tsx`, `src/components/hero.tsx`, `src/app/page.tsx`, `src/app/globals.css`, `src/data/portfolio.ts`, `scripts/emerald-browser-qa.mjs`, `README.md`, and this report.

The initially modified next-env.d.ts is generated by Next.js; it is not part of the design change.

## Validation
Passed: ESLint, TypeScript, production build, HTTP smoke checks and Edge/Playwright browser checks. The logo/wordmark and decorative project images are absent; all five project cards, one Team Project/four Personal Projects, all seven certificates, both CV downloads, filters, mobile navigation, focus outlines, reduced motion and contact validation passed. Both themes passed at 320, 375, 390, 430, 768, 1024 and 1440px without horizontal scrolling. Portrait decoding and non-zero image dimensions are checked at every width before screenshots. Desktop cards, compact skills/certifications and mobile portrait screenshots were reviewed. No remaining issues found for this update.
