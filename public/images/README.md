# Portfolio images

Original supplied portrait: `sylvie-profile.png`, retained unchanged and used in About. Hero uses `sylvie-portrait-cutout.png`, a background-extracted derivative made with built-in image_gen and genuine PNG transparency. The original face/pose was the preservation target. See HERO_UPDATE.md for the exact prompt and validation details.

The shared profile settings include profileImage (original), heroImage (transparent cutout), and showProfileImage. Hero uses a frameless image, object-fit: contain, no filters, and a bottom fade; the surrounding emerald glow comes from CSS.

Project covers are original vector illustrations in `projects/`, labeled as illustrations on each card. They may be replaced with genuine screenshots using the project data fields image, imageAlt and imageKind.

The older sylvie-profile.jpg is retained but is not displayed.
